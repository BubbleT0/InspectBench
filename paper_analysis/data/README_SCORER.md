## 1. 概述与设计目标

本评分器评测视觉语言模型（或任意管线）作为"图片异常评审器"的能力：

1. **找全**：有错图上的所有异常区域都要被框到；
2. **框准**：预测框要贴住异常，不带入过多背景、不严重偏大偏小；
3. **克制**：不重复框同一异常、不在背景上乱框；
4. **不误报**：无错图上尽量不输出任何框。

设计上刻意做到：

- **连续计分而非二值匹配**：不做 IoU>0.5 才算命中的硬门槛，每个真值获得 [0,1] 的连续质量分，主分因此可微、可区分细粒度差异；
- **多对一允许**：一个大框合理覆盖多个相邻异常不被惩罚（合法合并），但会接受紧致度与面积惩罚；
- **重复框零信用**：同一异常被多个框重复覆盖时只有归属者得分，其余框计入误报侧；
- **类别与描述不进主分**：预测的类别字段和自然语言描述只用于诊断，杜绝"类别蒙对得分"或"描述写得好得分"。

指标版本标识：`merged-ground-truth-ownership-v2`。

## 2. 输入格式

### 人工标注（JSONL，每行一图）

```json
{
  "sample_id": "唯一图片编号",
  "image_absolute_path": "/path/to/image.png",
  "image_width": 2048,
  "image_height": 3072,
  "prompt": "原始生成提示，可为空",
  "annotation": {
    "no_error": false,
    "boxes": [
      {"bbox_xywh": [1363.71, 1879.61, 96.0, 96.0],
       "error_type": {"code": "D1_Artifact/A2_StructuralArtifact"},
       "detail": "手部结构异常"}
    ]
  }
}
```

约束（加载时强校验，违反即报错）：

- `sample_id` 全局唯一；
- 无错图必须 `no_error=true` 且 `boxes=[]`；有错图必须 `no_error=false` 且至少一框；
- `bbox_xywh` 为原图绝对像素坐标 `[左上x, 左上y, 宽, 高]`，必须落在图片范围内；
- `error_type.code` 必须属于六个一级类别（`D1_Artifact/A1..A4`、`D2_TextCorrectness/A1..A2`）。

### 模型预测（JSONL，每行一图）

```json
{
  "sample_id": "同标注的 sample_id",
  "model": "配置名",
  "status": "ok",
  "boxes": [
    {"bbox_1000_xywh": [100.0, 200.0, 300.0, 400.0],
     "family": "D1_Artifact/A2_StructuralArtifact",
     "description": "可见的异常证据"}
  ],
  "no_error": false
}
```

- 坐标归一化到 0–1000（相对图片宽高），内部转换为绝对像素再计算；
- `status` 非 `"ok"` 的记录按**空预测**参与评分（见第 11 节）；
- 未知类别被忽略，但框仍参与所有定位计分。

## 3. 坐标系统

- 真值：绝对像素 `[x, y, w, h]`（左上角 + 尺寸）；
- 预测：归一化 0–1000 的 `[x, y, w, h]`，加载后按 `width/1000`、`height/1000` 缩放为绝对像素；
- 所有几何计算（交集、并集、面积比）都在绝对像素空间进行，因此同一预测在大图与小图上的行为一致。

## 4. 基础配对质量

对单个预测框 P 与单个真值框 G，设交集面积 I：

```
覆盖率   C = I / |G|     —— 异常区域被框全了多少（找全）
紧致度   T = I / |P|     —— 预测框里有多少是真值（不带背景）
Dice     D = 2CT / (C+T) —— 两者的调和平均，等价于矩形区域的 Dice 系数
```

- C 高 T 低 = 框太大（罩住了异常但带入大量背景）；
- T 高 C 低 = 框太小（贴住了一部分异常但漏掉了其余部分）；
- 基础分 = `D^0.7 × ψ`，其中 ψ 是面积惩罚（下一节）。指数 0.7 略微宽容中等水平的 Dice：D=0.5 时贡献 0.5^0.7≈0.61，避免对"基本框住"的框过度惩罚。

这一步只用于 **ownership 选举和诊断**；真值的最终质量在第 7 节的合并重算中确定。

## 5. 面积惩罚函数 ψ

预测面积与真值面积之比 `r = |P| / |G|` 不需要恰好为 1——小真值允许更大的相对误差（96px 的框画成 130px 很正常，2000px 的框画成 2700px 则不应 tolerated）。容忍度由真值占全图面积的比例 `f = |G| / |image|` 决定：

```
τ(f) = 1.25 + 0.35 · exp(−f / 0.01)
```

**具体插值方式**：这不是分段线性插值，而是一条连续的指数衰减曲线——

- `f → 0`（无穷小真值）：τ → **1.60**，即允许面积比在 [1/1.60, 1.60] ≈ [0.625, 1.60] 内不受罚；
- `f = 0.01`（占全图 1%，衰减特征尺度）：τ = 1.25 + 0.35/e ≈ **1.379**；
- `f → 1`（真值覆盖全图）：τ → **1.25**，面积比必须落在 [0.8, 1.25] 内才不受罚。

τ 是**对称容忍带**：超出容忍带的对数超额为

```
e = max(0, |ln r| − ln τ)
```

`|ln r|` 对 r<1（框偏小）和 r>1（框偏大）同等处理。最终高斯惩罚：

```
ψ(e) = exp(−4e²)
```

数值感受：e=0（容忍带内）ψ=1；e=0.25 ψ≈0.78；e=0.5 ψ≈0.37；e=1 ψ≈0.018。即面积比超出容忍带 e≈ln1.6−ln1.25≈0.25 倍时已扣掉约 22%，超出 2.5 倍容忍带几乎清零。

**为何用指数衰减而非分段**：容忍度随真值大小变化是平滑的物理事实（标注小框本身就有更大的相对抖动），指数曲线没有分段边界处的不连续，任何 f 上的微调都不会造成分数跳变。

## 6. Ownership 归属与 tie-breaking

**规则：每个真值由恰好一个预测框认领；一个预测框可以认领多个真值。**

选举流程（对每个真值 G_k）：

1. **候选集**：所有与 G_k 有正覆盖率的预测框（`C(P_j, G_k) > 0`，即交集面积 > 0）。完全不相交的预测不参与选举；
2. **排序键（依次比较）**：
   - ① **覆盖率更高者胜**（先把异常框全最重要）；
   - ② 覆盖率完全相等时，**基础 1 对 1 质量分更高者胜**（box_pair_stats 的 score，即 Dice 与面积惩罚的综合）；
   - ③ 仍相等时，**模型输出顺序更靠前者胜**（确定性 tie-break，保证结果可复现且不偏向靠后的输出）。

实现为 `max(candidates, key=(coverage, score, -pred_index))`。

推论：

- 一个大框可以认领多个相邻真值（合法合并，见第 7 节）；
- 多个框重复覆盖同一真值时，只有归属者得到信用，其余框信用为 0（计入重复误报或背景误报）；
- 覆盖率优先于基础质量意味着：一个覆盖 90% 但带 50% 背景的框会胜过一个覆盖 60% 但完全紧致的框——评测优先"找到并框全"。

## 7. 合并框

若预测 P 认领了 K ≥ 2 个真值，最终质量不是各自 1 对 1 分数，而是以**这 K 个真值矩形的几何并集 U** 为目标重算：

```
T_merge = |P ∩ U| / |P|          （紧致度对并集计算）
r_merge = |P| / |U|              （面积比对并集计算）
τ_merge = τ(|U|/|image|) · √K    （容忍度按认领数量开方放宽）
```

- 每个被认领真值仍**各自**计算覆盖率 `C_k = |P ∩ G_k| / |G_k|`；
- 每个真值的最终分 `s_k = D_k^0.7 · ψ(e_merge)`，其中 D_k 由 C_k 与共享的 T_merge 合成，面积惩罚 ψ 对整个组共享。

**√K 放宽的理由**：两个真值即使紧邻，其并集的"合理包络"也天然大于单个真值的合理包络；√K 是周长/面积量级的自然缩放（盒包住两个物体通常需要在每个维度各多容纳一些边界）。

效果：一个紧致大框包住两个异常能拿到接近两个 1 对 1 的分数；一个罩住半张图、只为了顺带盖住两个小异常的框，会被 T_merge 和 ψ(e_merge) 双重压低。

并集面积用坐标扫描线精确计算（对 x 边界分段，段内对 y 区间做合并覆盖长度），不是近似。

## 8. 单图计分

设某有错图有 M 个真值、N 个预测框，真值最终质量为 s_k，预测框信用为 u_j：

- **真值质量总和 / 软召回率**：`Q = Σ s_k`，`R = Q / M`
- **预测信用**：认领了真值的框，信用 = 其认领真值质量的**平均**；未认领任何真值的框（重复框、背景框）信用 = 0
- **软精确率**：`P = Σ u_j / N`
- **图片分**：`F = 2PR / (P+R)`（调和平均）

行为解读：

- 漏检压低 R（漏掉的真值 s=0 进分母）；
- 重复框/背景框压低 P（信用 0 进分母 N）；
- 调和平均确保短板决定上限——找全但全是烂框 ≈ 框准但漏一半，都不高分。

## 9. 无错图计分

无错图（M=0）只看预测框数 N：`F = exp(−N)`。

| N | F |
|---|---|
| 0 | 1.000 |
| 1 | 0.368 |
| 2 | 0.135 |
| 3 | 0.050 |
| 4 | 0.018 |

不关心框的位置——无错图上任何框都是误报，只惩罚数量，且边际递减（第 1 个误报已经扣掉 63%，后续每个框的边际惩罚递减）。

## 10. 正式主分

两级聚合：

**有错图弹性分**（按每图真值数平方根加权）：

```
S_positive = Σ_{M_i>0} √M_i · F_i / Σ √M_i
```

多错误图片权重略高但不线性放大，避免极少数密集图片支配总分。

**无错图软分**：`S_clean = mean(exp(−N_i) | M_i=0)`

**正式区域框主分**（0–100，w=0.7、幂指数 r=0.5 的加权幂平均）：

```
S_main = 100 · (0.7·√S_positive + 0.3·√S_clean)²
```

有错图占 70% 权重；幂平均下任何一侧为 0 都会把总分压向 0（√ 之后加权再平方），模型不能靠单一能力拿高分。

**两个区域诊断分**（不进主分）：按人工真值类别拆成 `artifact_region_bbox_score`（D1_Artifact/*）与 `text_region_bbox_score`（D2_TextCorrectness/*）。每张含目标类别的图取该类真值质量均值，按 √K_i 加权（K_i 为该图目标类真值数）。它们不含无错图克制项，不能相加或加权还原主分。

## 11. 失败样本的分数填补策略

**规则：status 非 "ok"（error/missing）或预测文件中根本不存在的 sample，一律按"空预测"（N=0、无框）参与评分，样本不剔除、不重跑。**

具体后果：

- **有错图失败 → 图片分 0**（M>0、N=0 时软召回率为 0，调和平均为 0）；
- **无错图失败 → 图片分 1**（exp(−0)=1），表面上"完美克制"；
- 无预测记录的样本在实现中 `prediction=None`，等价于空框列表。

因此报告必须**同时给出 `failed_or_missing_predictions` 数量**：一个在无错图上大量失败的模型会获得虚高的 clean_soft。这是有意的设计（失败不能被静默丢弃，否则失败率成为免费的分数操纵手段），代价是无错图侧的分数需要结合失败数解读。

## 12. 诊断指标

| 指标 | 定义 | 方向 |
|---|---|---|
| recall@0.1 / 0.5 / 0.75 | 真值最终质量 ≥ 阈值的比例 | ↑ |
| 完全漏检 | 真值与所有预测框交集为 0（无任何候选） | ↓ |
| 有效漏检 | 最终质量 < 0.1 的真值数（含完全漏检 + 低质量相交） | ↓ |
| 已找到框平均质量 | 仅质量 ≥ 0.1 的真值的平均分 | ↑ |
| 数量 MAE / 偏差 | mean(\|N−M\|) / mean(N−M)（正=多报，负=少报） | ↓ / →0 |
| 合并预测 | 认领 ≥2 真值的预测框数（本身中性） | — |
| 拆分候选 | 被 ≥2 个预测以基础质量 >0.1 覆盖的真值数 | ↓ |
| 重复误报 | 未认领真值、但重复覆盖已认领异常（质量>0.1）的框数 | ↓ |
| 背景误报 | 未认领真值且不属于重复覆盖的框数 | ↓ |
| 有/无错图误判率 | 图片级二分类（有框=判有错）的错误率 | ↓ |
| 无错图平均预测框数 | ΣN / 无错图数 | ↓ |
| 类别正确率 | 已找到（质量≥0.1）且提供类别的配对中类别相等比例（仅诊断） | ↑ |

## 13. 置信区间

默认 2000 次分层 bootstrap：

1. 分别对有错图集合和无错图集合**有放回**等量重采样；
2. 每次重采样后完整重算 headline 指标；
3. 95% CI 取第 2.5 / 97.5 百分位（线性插值分位数）。

分层保证两侧样本量不变，CI 只反映图像层面的抽样波动。注：独立开源版使用标准库 `random.Random(seed)`，与仓库参考实现的 numpy RNG 流不同，CI 边界可能有 ±0.1 量级的差异，但点估计完全一致。

## 14. 类别与描述字段的处理

- **预测的 family / 类别**：不参与主分。仅用于诊断指标"已找到框上的类别正确率"，且只统计质量 ≥0.1 且提供了类别的配对；未知类别忽略但不影响定位得分。
- **Artifact/文字区域诊断分完全按人工真值类别分组**，不读预测类别——预测类别缺失或错误不会改变分组，其他类别的正确预测也不会被当作该组误报。
- **描述文本（description/detail）**：不参与任何评分，仅供人工复核模型"为什么画这个框"。

## 15. 使用方法

```bash
python bbox_scorer.py \
    --annotations gt_part1.jsonl gt_part2.jsonl \
    --predictions model_a_predictions.jsonl \
    --output metrics.json \
    --per-sample-out per_sample.json \
    --bootstrap 2000 --seed 20260804
```

- 零第三方依赖（纯 Python ≥3.9 标准库），单文件；
- `--output` 省略时打印到 stdout；`--bootstrap 0` 跳过 CI 加速调试；
- 逐样本结果（含每图 M/N/Q/P/R/F、漏检、误报）写入 `--per-sample-out`。

校验：`verify_equivalence.py` 在 1039 图真实数据上对比独立版与仓库参考实现，全部 headline/检测/计数/误报指标逐位一致（见仓库内运行记录）。

## 16. 已知限制与解读注意

1. **失败样本策略的双刃剑**：无错图失败得满分 1，必须结合 `failed_or_missing_predictions` 解读 clean_soft；
2. **数量正确 ≠ 位置正确**：N=M 的图可能框全在错误位置；数量指标必须与召回率/质量一起看；
3. **已找到框平均质量的幸存者偏差**：不含质量 <0.1 的真值，只框到少量容易异常的模型均值可能虚高，需与召回率并读；
4. **合并预测数本身中性**：紧致合并是允许行为，需结合质量解读；
5. **区域诊断分不可加**：不含克制项，不能相加/平均/加权还原主分；
6. **覆盖率优先的 ownership**：带背景的大覆盖框可能赢走紧致小框的归属权——这是"找全优先于框准"的显式价值排序，如需相反排序需修改第 6 节的 tie-break 键序；
7. **纯无错图子集不能评检出能力**：只能衡量误报克制。
