# Paper analysis assets

`scripts/` and `data/` preserve the paper's table/figure generation code, failure-bound audit and supplied aggregate results. These are separate from the full image/prediction analysis in `../reproducibility/`.

Run the scripts from this directory's layout after installing `requirements.txt`. Outputs go to local `tables/` and `figures/` directories. No LaTeX compilation is needed for score reproduction; the submitted manuscript and Figure 2 were not modified during this code release.
