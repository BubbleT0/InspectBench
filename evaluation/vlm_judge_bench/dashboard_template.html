六步看懂正式主分

这里仅介绍真正决定主分的公式。辅助诊断指标统一放在后半段字典中。

1

评测在回答什么

对有错图，模型既要找出所有异常，又要把框画准，还不能输出太多重复框和背景框。对无错图，模型最好完全不输出框。

Mi = 第 i 张图的真值框数
Ni = 第 i 张图的预测框数

最终主分综合两侧能力，任何一侧明显较弱都会拖低总分。

2

一个预测框画得好不好

覆盖率 C：异常有没有框全。

C = 交集面积 ÷ 真值框面积

紧致度 T：框里有没有太多背景。

T = 交集面积 ÷ 预测框面积

二者先取调和平均：

D = 2CT ÷ (C + T)
↔
面积惩罚检查预测框是否明显过大或过小

先计算面积比：r = 预测框面积 ÷ 真值框面积

r = 0.5预测框只有一半
r = 1大小完全一致
r = 2预测框大一倍
τ 是允许误差。绿色范围内不额外扣分，超出越多惩罚越强。
小异常
0.625 倍1 倍1.60 倍
大异常
0.80 倍1 倍1.25 倍

小异常的 τ 接近 1.60，允许较大的相对误差；大异常的 τ 接近 1.25，要求更严格。当 1/τ≤r≤τ 时，面积惩罚为 1。

e = max(0, |ln r| − ln τ)
面积惩罚 = exp(−4e²)
r = 0.5⇄r = 2受到相同程度的面积惩罚

原因是使用了 |ln r|：缩小到一半和放大到两倍在对数尺度上距离相同。

s = D0.7 × exp(−4e²)

s=1 表示完全一致，s=0 表示没有交集。位置重叠和面积尺度必须同时合理。

3

一个大框能否覆盖多个异常

每个真值最多只能给一个预测框记分；一个预测框可以认领多个真值。

a(k) = 覆盖第 k 个真值最完整的预测框

合理合并：一个紧致大框圈住多个相邻错误，可以获得信用。

重复报框：多个框重复圈同一错误时，只有所有者获得信用，其余框信用为 0。

若一个框认领多个真值，先合并真值区域，再检查大框是否紧致、是否过大。

4

一张有错图怎样评分

示例：一张图有 3 个真值。模型输出 2 个框：第一个框认领两个异常，质量为 0.8 和 0.6；第二个框在背景上，信用为 0；第三个异常漏检，质量为 0。

软召回率：每个真实异常获得 0 到 1 的质量，再取平均。

Qi = Σ sik
Ri = Qi ÷ Mi = (0.8+0.6+0)÷3 = 0.467

预测框信用：一个框认领多个真值时，信用取这些质量的平均。

ui1 = (0.8+0.6)÷2 = 0.7
ui2 = 0

软精确率：所有预测框信用取平均。

Pi = Σuij ÷ Ni = (0.7+0)÷2 = 0.35
有错图图片分
Fi = 2PiRi ÷ (Pi+Ri) ≈ 0.40
它同时要求尽量找全、框得准确、少输出无效框。

无错图只看模型画了多少个框：

Fi = exp(−Ni)

6

整个配置怎样得到正式主分

有错图弹性分
Spositive = Σ[√Mi · Fi] ÷ Σ√Mi

错误更多的图片权重稍高，但不会按错误数量成倍放大。

无错图软分
Sclean = mean[exp(−Ni) | Mi=0]

衡量模型在正常图片上是否克制。

正式区域框主分
Smain = 100 · (0.7√Spositive + 0.3√Sclean)²

采用 w=0.7、r=0.5 的加权幂平均，有错图占 70% 权重，无错图占 30% 权重。

评分限制与注意事项

结果不能脱离这些条件解读

失败样本：失败或缺失被转换为空预测。有错图失败得 0 分；无错图失败因没有框会得到 1 分，必须结合失败数量解读主分。
类别：Artifact/文字区域框分依据人工真值类别拆分，模型预测类别不参与；两项是定位诊断分，不能相加还原正式主分。预测类别仍只用于“已找到框上的类别正确率”。
合并框：一个大框可以认领多个真值，但仍接受紧致度和面积惩罚；“合并预测数”本身不是好坏结论。
数量指标：框数正确不代表位置正确，多报与少报还可能在数量偏差中互相抵消。
分桶：样本少的桶波动较大，应同时查看图片数或真值框数。
柱形图：比例按 0 到 100% 绘制，计数按同行最大绝对值缩放；跨指标行不能直接比较长度，准确值以数字为准。
