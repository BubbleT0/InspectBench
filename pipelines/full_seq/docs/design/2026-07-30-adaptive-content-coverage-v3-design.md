# Adversarial Consensus V3：自适应内容覆盖设计

## 目标

V3 在 V2 的核心缺陷门槛、真实裁剪复核和最终整编规则上，将固定 `3×3` 文字分块替换为按图片内容生成的自适应区域。

第一性原理保持不变：找出图中肉眼明显的 Artifact 和明显文字错误，并框出适合交给后续 edit 模型局部重绘的独立区域。人工指出的样本只用于发现通用失败模式，不得形成样本 ID、具体文案、场景或坐标特例。

V3 必须与 V2 使用独立的输出目录、结果文件和 HTML。V2 的数据和页面不得覆盖、删除或原地修改。

## 方案选择

考虑三种方案：

1. 双通道语义切分：分别建立全部可读文字块清单和主要独立实体/版面区块清单，再逐块检查。适合自然摄影、海报、论文图、动漫等混合内容，作为 V3 采用。
2. 传统视觉算法切分：通过 OCR、连通域和边缘生成区域，速度较快，但难以稳定理解自然图像中的实体、复杂排版和生成式伪文字。
3. 语义切分加自适应网格兜底：召回可能更高，但会重新引入与内容无关的切块，调用量难以控制，也偏离按独立区块或实体检查的目标。

## 语义内容清单

V3 在任何缺陷判断之前，通过两个相互独立的结构化通道建立内容清单：

- 文字通道枚举原图分辨率下所有“被设计为文字内容”的语义编辑单元；即使当前渲染为乱码、伪文字或完全不可读，也必须进入清单。
- 实体通道枚举主要独立实体和具有完整语义的版面区块，包括人物、动物、物体、建筑、图表、插图、信息卡片和其他需要单独检查的视觉单元。

文字语义编辑单元以“一次局部重绘应当共同修复的完整内容”为边界，不以单行、单词、字符数量或固定面积为边界：

- 主标题使用完整标题区域。
- 信息卡片中的标题和正文属于同一视觉容器且需要共同重绘时，合为一个卡片文字单元。
- 表格、榜单或时间线的一整行属于一个单元，包括该行关联的序号、名称、说明、年份和数值。
- 空间独立的标签、按钮或蓝色标注各自保持为完整独立单元。
- 同一说明面板中的连续正文整体作为一个单元，不按换行拆碎。
- 只有当两个文字区域在视觉容器、语义用途和局部重绘目标上均独立时才拆开。

每个文字候选返回稳定的 `semantic_group_id`、`semantic_unit_kind` 和 `boundary_complete`。同一语义组被模型拆成多行或多个词时，程序按 `semantic_group_id` 合并成完整 bbox。`boundary_complete=false` 的候选不能直接进入缺陷检查。

`content_kind=text` 是文字语义的唯一程序判据。模型返回的“当前是否可读”等布尔判断不得取消文字属性；被设计成文字但已经乱码或完全不可读的区域仍必须接受全部文字检查。

`semantic_group_id` 只允许合并文字通道中类型一致的完整语义单元，不能用于合并空间分离的实体、卡片或独立标签。模型把一整行实体共用同一组 ID 时，各实体仍按各自 bbox 保持独立。

内容清单面向正常内容和异常内容，不允许只列出整图初筛认为可疑的区域。清单阶段不判断审美或世界知识，也不把图片目录名、文件名、参考标签或其他答案线索发送给模型。

## 区域规范化

两个清单返回的 bbox 映射到原图归一化坐标后统一规范化：

- 同一文字或实体由多个通道重复提出时，合并为一个内容区域；同一 `semantic_group_id` 的多个文字碎片即使不重叠也合并为完整语义单元。
- 空间分离的标签、按钮、卡片或实体必须保持独立，禁止用一个覆盖整片场景的大框替代。
- 一个语义完整的标题、卡片、榜单行、正文面板、图表或实体保留为单一区域；不得为了得到更小的框而破坏其完整性。
- 边界完整的标题、卡片、榜单行或连续文字面板优先于其内部的行、词和字符碎片；碎片不得通过聚合抑制反向删除完整语义单元。
- 包含至少两个空间独立子实体且面积显著更大的聚合框被拆除，以子实体区域为准。
- 裁剪框在原内容区域外保留约 `8%` 上下文，并限制在原图边界内，使检查结果可直接转化为 edit 模型的局部重绘区域。

## 裁剪边界完整性

局部裁剪只用于放大检查，不能创造原图中不存在的缺字或截断问题。每次区域检查都同时提供原图与裁剪图，并先完成边界完整性判断：

- 若原图显示同一语义单元仍延伸到裁剪框外，当前裁剪判为不完整，`issues` 必须为空。
- 模型返回覆盖完整语义单元的全图归一化修正 bbox，程序自动扩框、重新裁剪并再次检查。
- 裁剪中出现而原图完整语义单元中不存在的断头词、半行文字、孤立年份或字符残片，一律视为裁剪伪影，不能成为 finding。
- 整图清单与局部裁剪判断冲突时，以整图中的完整语义单元为边界；局部碎片不得覆盖整图的正常结论。
- 一次修正后仍无法确认边界完整的区域记录为覆盖失败，不输出缺陷结论，也不得用碎片结果替代。

所有模型返回的 bbox 统一使用原图归一化坐标，不使用裁剪图局部坐标。文字区域一旦确认存在核心问题，最终 finding 直接使用完整语义编辑单元 bbox，避免模型再次把卡片、榜单行或标题缩成一行或几个词；非文字实体才允许在已检查语义单元内部返回更局部的原图编辑 bbox。

## 小区域无损放大

边界完整的内容区域裁剪以 PNG 传递，避免新增 JPEG 压缩损伤。若裁剪图短边小于 `768` 像素，则采用整数倍最近邻像素复制放大，直到短边尽量达到 `768` 像素，放大倍数最多为 `4`。

放大过程不得使用锐化、降噪、插值重建、生成式超分或任何可能创造新笔画和纹理的增强方法。原图和放大裁剪图同时传给复核阶段：原图提供上下文，放大图提高小区域在模型视觉输入中的占比。

## 区域检查

每个内容区域独立检查：

- 每个文字区域由两个独立发现专员交叉检查：`Text Visual` 覆盖乱码、伪文字、缺字、多字、笔画断裂粘连和扭曲；`Text Fidelity` 覆盖无需外部知识即可确认的明显格式错误和图内逐字矛盾。任一专员发现核心问题即可进入后续复核，两个专员的结果按同一语义单元合并为一个 finding；“当前不可读”本身不能让该区域退出检查。
- 实体和版面区域由 `Artifact` 专员检查明显局部渲染破损、实体结构错误、拓扑错误以及明显的关系和物理错误；同时由独立的 `Embedded Text` 专员检查其中全部可见文字。即使文字清单漏掉一张卡片，其实体清单仍提供文字召回兜底。

只报告 `major` 或 `critical`、`visible_only` 且最终置信度严格大于 `0.6` 的问题。清晰的风格化文字、世界知识、美观偏好和不影响可信度的轻微 AI 瑕疵继续跳过。

整图审查保留为内容覆盖终审，用于指出内容清单是否明显漏掉可读文字块或主要实体。若发现漏项，只补充对应的内容区域并执行同样的裁剪检查，不允许整图终审直接绕过区域检查产生最终 finding。

## 最终整编

V3 复用 V2 的 edit-ready 最终整编规则：

- 同一语义编辑单元存在多个问题时只输出一个 bbox，并在详情中完整描述全部问题；若卡片或榜单行内大量文字均损坏，bbox 覆盖完整文字单元，不拆成逐行或逐词小框。
- 空间独立区域的问题保持独立 bbox。
- 最终 bbox 以可供 edit 模型完成一次局部重绘为准，允许少量上下文冗余，不追求贴边最紧框。
- 不输出全图框、跨多个独立实体的大框、低置信度问题或不属于核心错误的问题。

## 全量对比与可视化

V3 使用与 V2 相同的 30 张输入图片、同一模型和相同的核心质量门槛，全量从头运行。V3 不复用 V2 的中间结果。

V3 HTML 独立展示：

- 原图和带编号 bbox 的叠加视图；
- 自适应内容清单及各区域类型；
- 原始裁剪尺寸、上下文扩展范围和放大倍数；
- 每个区域的中文检查轨迹；
- 被接受和被丢弃的问题及原因；
- 最终 edit-ready 区域和完整问题描述。

V2 与 V3 分别保留独立 HTML，并提供不会互相覆盖的访问路径，以便人工并行查看和对比。

## 验收标准

- V3 的 30 张图片均运行成功，结构化输出与 grounding 校验通过。
- 不再生成固定网格裁剪；裁剪均来自可追溯的文字块、独立实体或版面区块。
- 所有被设计为文字内容的语义编辑单元和主要独立实体都有内容清单记录和区域检查轨迹，乱码文字不会因“当前不可读”被过滤。
- 每个文字语义单元都有 `Text Visual` 和 `Text Fidelity` 两条独立发现轨迹，任一专员的有效结果都不会因另一专员漏判而丢失。
- 每个实体或版面区块都有独立的 `Embedded Text` 兜底轨迹；实体清单中的同排卡片不得因共享组 ID 合并成大框。
- 信息卡片、榜单行、完整标题和连续说明面板不按单行、单词或固定面积拆碎；空间独立标签仍保持独立。
- 裁剪边界不完整时自动扩框重裁，任何裁剪制造的残词、缺字或截断都不会进入最终 finding。
- 小区域使用 PNG 整数倍像素复制放大，没有新增压缩、锐化或生成式增强。
- 最终只包含明显 Artifact 和明显文字错误，置信度严格大于 `0.6`。
- 同一区域的多个问题合并描述，空间独立的实体不合并成大框。
- 不存在样本 ID、具体文案、年份、场景名或坐标驱动的特例代码。
- V2 和 V3 的输出目录、结果文件与 HTML 均独立保留。
