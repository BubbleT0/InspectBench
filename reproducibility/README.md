# InspectBench scoring and rebuttal analyses

This package reproduces scores and offline analyses from fixed predictions on 1,039 images. It includes 17 normalized prediction files and geometry-only reference annotations. Public sample IDs match the benchmark images and the original v1.0 annotation release. Image bytes are distributed separately; annotator identities, private endpoints and credentials are excluded.

Run `python -m unittest discover -s scorer -p 'test_scorer.py'` for the 24 specification tests. Run `python analysis/analyze_existing.py` for full rescoring, ownership diagnostics, source strata, conventional matching, geometric/aggregation sensitivity, and paired bootstrap intervals. The analysis requires NumPy and SciPy and invokes no models. The frozen scorer itself uses only the Python standard library. Results are written to `analysis/results/` and baseline scores are asserted against the supplied reference values.

Quality-first changes election priority only; group unions are then recomputed. Ownership reversal counts compare pre-group pair quality, and rescued/lost threshold crossings separately reflect final group credit. One-to-one matching is class-agnostic maximum-cardinality IoU-threshold matching with IoU as a tie-break, not SDG-Eval or mAP. Sensitivity changes one setting at a time. Removing the area penalty is an extreme ablation, not a proposed default. Paired bootstrap uses 10,000 flawed/clean-stratified image draws (NumPy default_rng seed 20261112); intervals are pointwise, conditional on fixed predictions, and do not measure retraining variability.

`inference/stored_settings.json` preserves whitelisted Direct runner settings. `direct_prompt.txt` and `prompting_source.py` recover the available prompt implementation, not an immutable request archive for every historical run. The OpenAI-compatible adapter initially submits native image bytes when image_max_side is null, or resizes to the configured maximum side and JPEG quality; it retries HTTP 413 with smaller views down to 768 pixels. Additional recovered pipeline settings are in `../pipelines/configurations/`, and actual checkpoint argument snapshots are in `../training/checkpoints/`. These improve configuration provenance without reconstructing every historical call or making training possible without the original data, weights and environment.

The Decision-SFT separation audit covers the identified 4,000/800 train/validation manifest and all 1,039 benchmark images. File hashes and a specified 63-bit perceptual screen found no cross-split matches/candidates. The cached fingerprints permit exact-hash comparisons; regenerating image fingerprints requires the source images, which are not distributed here. It does not certify other checkpoints, all transformed duplicates, semantic overlap, or pretraining separation. No new human label audit was performed.

Historical cost logs concern 1,054-image execution batches, not the final 1,039-image scoring inputs. Do not combine their wall times and the final scores as a synchronized cost-quality experiment. The package supports scoring reproducibility, not compute-matched causal attribution.
